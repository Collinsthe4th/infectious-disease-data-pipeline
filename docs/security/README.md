# Security, data and ethics

## Data handled
- **Public, aggregated** counts from NCDC situation reports (no individual patients, no personal data).
- Public reference data from HDX (place codes, population).
- **Synthetic** demo data generated by the project; always labelled (`SYNTHETIC_` file names, `is_synthetic` columns, dashboard banner).

## Responsible collection
- Clear user agent with the project URL; at least 5 s between requests; robots.txt respected; only report PDFs and listing pages are requested.
- Failed downloads go to a manual queue instead of being retried aggressively.
- NCDC remains the authoritative source; the pipeline never replaces an NCDC figure with a secondary source (Section 3.4.1).

## Secrets
- The only secret is the database password. Docker Compose uses a local default; for any shared or hosted database put `DATABASE_URL` in `.env` (git-ignored) or a CI secret. Never commit `.env`.
- A future ERA5 key goes in `~/.cdsapirc` (git-ignored).

## Interpreting outputs
- Recent weeks are provisional and may be revised; the naive CFR is biased during outbreaks (Ghani et al., 2005).
- Alerts are statistical signals for attention, not confirmed outbreaks. Forecasts carry intervals and are not official projections.
